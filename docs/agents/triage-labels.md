# Triage labels

Use these exact GitHub label names for the five triage roles:

| Role | GitHub label | Use when |
| --- | --- | --- |
| Needs triage | `needs-triage` | The issue still needs maintainer evaluation. |
| Needs information | `needs-info` | The reporter must provide missing details. |
| Ready for agent | `ready-for-agent` | The work is specified well enough for an unattended agent. |
| Ready for human | `ready-for-human` | A person needs to implement or decide the work. |
| Won't fix | `wontfix` | The project will not act on the issue. |

Do not substitute a second label vocabulary for these roles. Apply and remove the labels with `gh issue edit`.
